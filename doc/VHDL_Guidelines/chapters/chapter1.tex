\chapter{Introduction}	


\section{Purpose}
This document aims to provide a consistent development guideline for everything to do with VHDL. This is to improve readability, as well as maintainability of code, written by multiple people.

\section{Scope}
This standard applies to all VHDL modules, testbenches and associated files developed for the data link layer of the TM link of ERWIN.
