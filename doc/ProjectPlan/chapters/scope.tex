\chapter{Scope}
The scope of this project is bounded by CCSDS 132 and CCSDS 131. These standards define the ground and on board side of open systems interconnection (OSI) layer 2 (data link layer). Appropriate interfaces to all inbound and outbound systems will be provided, defined in the respective ICDs. Furthermore, an emulation of all relevant systems for a full hardware in the loop validation will be developed, if not already developed and supplied by SeeSat. As the relevant ICDs have not been supplied at the time of writing, it is assumed that one instance of this system will be integrated into the OnBoard programmable logic (PL) for every physical TM channel.
